# 全10ステージの作業計画モード

各ステージの遊び方から「作業計画」を選択します。従来の練習・実力確認はそのまま利用できます。

Stage2〜10は「準備・実行手順・結果確認」の3問を選び、予想してから自動再生します。正常／異常の2状態があり、観察・追加確認・判断・記録まで体験できます。異常は停止して要対処として報告し、修理済みにはしません。失敗した判断からのやり直し、進捗表示、原因説明と振り返りも共通です。

| Stage | 判断する場面 |
| --- | --- |
| 2 | 段階的な電源投入、電圧・異臭の確認 |
| 3 | バックアップ、PLC診断とI/O構成 |
| 4 | 通信状態と局番重複 |
| 5 | センサーとPLC入力の対応 |
| 6 | 非常停止の実物と入力信号 |
| 7 | 出力と実機の対応、強制解除 |
| 8 | エアー投入と軸の動作方向 |
| 9 | 原点位置と完了信号 |
| 10 | 1サイクルの完了検出とワーク位置 |

各工程の要点を抜粋したシナリオです。残りの確認を省略する場面は画面で明示します。Stage2〜10は対象・工程・観察結果を表示します。以下はStage1固有の内容です。

1. 工具準備、通電・無電圧確認、使用するCP、測定レンジの4問で計画します。
2. 簡略工場でキャラクターが移動し、選んだ作業を順に自動再生します。一時停止・2倍速が使えます。
3. P−0V間の抵抗測定で止まり、切り分けと再測定後の判断を選びます。
4. 最後に後始末を選び、結果と理由を確認します。

計画の再生前に「測定結果の判断まで進む／途中停止／故障・発煙」のどれになるか予想します。対象は初期計画の再生で、その後の追加判断は含みません。初期計画の再生が止まった時点で予想と実際を比較します。予想は採点されず、シミュレーションの結果にも影響しません。選び直しでは予想をもう一度選びます。

失敗・完了時には「今回覚えておきたいこと」を1文で表示します。制御盤の損傷、テスターの損傷、準備不足、後始末など、今回の結果に対応した内容を示します。

主電源・CP1〜3のON/OFF、レンジ、測定端子を再生に合わせて表示します。計画画面と再生画面の「図面と測定の考え方を見る」で設計上の経路を確認できます。故障時は通電から損傷までの原因を赤い模式図で示します。

「失敗した判断からやり直す」は学習用の巻き戻しです。追加判断では直前の電源・CP・測定値を復元します。初期計画の修正では、同じ準備・確認の再生を省略して変更した操作から再開します。

このモードはStage1の要点を抜粋した学習用シナリオです。全測定を再現する自由操作モードとは別の記録・状態で動作し、スコア保存はしません。残りの導通確認を省略する箇所は画面で明示します。配線状態は回り込み／短絡の2種類。選び直しでは同じ状態を維持し、完了後に別の状態にも挑戦できます。

主電源投入の選択を初期計画・測定後・後始末に追加。短絡回路の通電や通電中の不適切なテスター操作では、制御盤／テスターに炎・煙を表示します。発煙は損傷を表す学習用演出で、実機で必ず同じ現象になるという意味ではありません。無電圧でのレンジ間違いや正常回路への通電を一律に発煙させず、状態に応じて結果を分けます。

検証：計38件のテスト。Stage1の既存分岐に加え、Stage2〜10の正常・異常判定、追加確認、準備・手順・確認の不足による停止、危険選択、引き継ぎ完了と省略時の停止を確認。
