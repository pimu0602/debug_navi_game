## Stage 1の4本柱

手順書Step 1〜11を全部細かく再現するのではなく、この4つの流れを体で覚えてもらうことがゴール。

1. **主電源OFF確認**(Step 1)— 何よりも先にやる
2. **無電圧確認**(Step 2)— レバーを見ただけで信用しない。テスターで実測する
3. **導通チェック**(Step 3〜10)— 図面と照らしながら、鳴るべき所が鳴り、鳴ってはいけない所が鳴らないことを確認する
4. **CP全OFF戻し**(Step 11)— 後工程の事故を防ぐ後始末

## 手順書Step 1〜11 → ゲームでの扱い

| Step | 工程名 | ゲームでの扱い | 備考 |
|---|---|---|---|
| 1 | 主電源OFF確認 | ◎ 再現 | 制御盤の「レバー位置を確認する」を選ぶ |
| 2 | 盤内無電圧確認 | ◎ 再現 | テスターVレンジでR-S間、L-N間、P-0V間を測定。AC/DCレンジ選択も判定に含める |
| 3 | 導通確認用CP ON | ◎ 再現 | 図面確認→必要なCPだけON。どのCPをONしたか自動記録(ペンの再現) |
| 4 | AC200V系 R/S/T/E 導通確認 | ◎ 再現 | Ωレンジで同線番ペア(R-R、S-S、T-T、E-E)を測定 |
| 5 | AC100V系 L/N/E 導通確認 | ◎ 再現 | 同上(L-L、N-N)。NとDC 0Vの混同が引っかけポイント |
| 6 | DC24V系 P/0V/E 導通確認 | ◎ 再現 | 同上(P-P、0V-0V) |
| 7 | 同一線番の導通確認(センサー線等) | △ 簡略化 | センサー線は代表2〜3本に絞る |
| 8 | 異線番どうしの短絡確認 | ◎ 再現 | R-S、R-T、S-T、L-N、P-0V等。「原則鳴らない。ただし抵抗値が見える場合は図面と照合」まで再現 |
| 9 | 電源線とE間の短絡確認 | ◎ 再現 | 地絡不良の発見場所。0V-E、N-Eは接地方式による判断も再現 |
| 10 | 回り込みの確認 | △ 簡略化 | CPがONのままだとP-0V間が導通に見える「罠」として実装。CPをOFFにして再測定すると消える |
| 11 | CP全OFF戻し | ◎ 再現 | 完了申告前の必須条件。忘れると軽ミス警告 |

**省略するもの:**

- テスターを当てる位置の使い分け(ネジ部ではなく圧着端子・電線部に当てる)→ 注意点テキストとして表示するだけ
- テスターのゼロ調整・電池確認などの器具メンテ
- 記録用紙への手書き記入 → ゲームが自動記録(確認済み箇所は図面にマーカー)

## できる操作の一覧

| 場所 | 操作 | 分類 |
|---|---|---|
| 工具置き場 | テスターを取る/ペンを取る | 準備 |
| 制御盤 | 主電源ブレーカーのレバー位置を確認する | 正しい操作(Step 1) |
| 制御盤 | 主電源をONにする | **危険な操作**(Stage 1では大ミス) |
| 制御盤 | CPを個別にON/OFFする | 正誤は状況次第(無電圧確認前だと軽〜中ミス) |
| 制御盤 | 端子台を調べる → テスター測定へ | 正しい操作 |
| テスター | レンジを切り替える(V-AC/V-DC/Ω) | 測定の一部 |
| テスター | 線番リストから2点を選んで当てる | 測定の本体 |
| 作業机/画面上部 | 図面を開く | いつでも可。見ずに操作すると軽ミス |
| ベテランNPC | 話しかける | いつでも可。回数記録 |
| 制御盤 | 「確認完了」を申告する | ステージ終了トリガー |

**測定点(端子台の線番リスト):**
R、S、T、E、L、N、P、0V の各線番が「盤側端子台」と「機器側端子台」の2か所にあり、同線番2点を選ぶと導通チェック、異線番2点を選ぶと短絡チェックになる。センサー線(例:X001、X002)を2〜3本追加。

## テスター判定ルール(Stage 1)

| 状況 | 結果 |
|---|---|
| Ωレンジ・同線番ペア(正常) | 「ピー」導通あり。図面に自動マーカー |
| Ωレンジ・同線番ペア(断線不良あり) | 鳴らない → 図面と照合して断線発見 |
| Ωレンジ・異線番ペア(正常) | 導通なし。ただし回路経由で抵抗値が見える場合あり(数値表示) |
| Ωレンジ・異線番ペア(短絡不良あり) | 「ピー」鳴ってしまう → 短絡発見 |
| Vレンジ・無電圧確認(正しいAC/DC選択) | 0V表示 → 無電圧確認完了 |
| Vレンジ・AC/DC間違い | 異常な値が表示され判断を誤る(中ミス扱い) |
| Ωレンジで通電中の回路を測定 | テスター破損(中ミス)→ 工具置き場で交換、時間ロス |

## 不良の種類一覧(ランダム仕込み対象)

| 不良 | 発見できるStep | 症状 |
|---|---|---|
| 異線番間の短絡(R-S間など) | Step 8 | 鳴ってはいけない組み合わせで「ピー」 |
| 同一線番の断線 | Step 4〜7 | 鳴るべき組み合わせで鳴らない |
| 電源線とE間の地絡 | Step 9 | 電源線-E間で導通してしまう |
| 線番の入れ違い(図面と実配線の不一致) | Step 7 | 図面通りの組み合わせで鳴らず、別の組み合わせで鳴る |
| 圧着端子の緩み(不安定導通) | Step 4〜7 | 同じ2点でも測るたびに結果が変わる ※実装が難しければフェーズ2で後回し可 |

毎プレイ0〜3件をランダムに仕込む。**0件の回もあり**(異常がないことを確認するのも仕事)。

## ミス3段階(Stage 1版)

| レベル | Stage 1での具体例 | 結果 |
|---|---|---|
| 軽ミス | 図面を見ずにCPを操作/不要なCPをON/CP戻し忘れのまま完了申告 | 警告イベント+減点 |
| 中ミス | 無電圧確認せずに導通チェック開始/AC・DCレンジ間違い/Ωレンジで通電回路を測定(テスター破損) | やり直し+時間ロス |
| 大ミス | 短絡・地絡を見逃したまま完了申告/Stage 1中に主電源をONにする | 発煙演出(コミカル)→ チェックポイントから再開 |

**チェックポイント:** ①無電圧確認完了時点 ②導通チェック完了時点

## 合格条件

- Step 1〜11相当の確認をすべて完了して申告
- 大ミス0回
- 仕込まれた不良をすべて発見・対処(不良0件の回は「異常なし」で申告)
