# 操作と学習モードの改善

- ブリーフィングで練習／実力確認を選択。スコアはモード別に保存・表示し、既存記録は練習として扱う。
- 練習では既存の端子自動選択・おまかせ測定・ベテランのヒントを維持。初回は工具準備と図面確認を案内する。
- 実力確認では端子・レンジの自動選択、おまかせ、ベテランのヒントを無効化。導通の測定値を見て正常／異常／切り分けを選ぶ。判断前は確認済みにしない。正常値の誤記録は不合格理由として残す。
- テスターからCP操作へ、CP操作からテスターへ直接切り替えられる。実力確認では選んだ端子とレンジを保持し、練習では確認待ちの箇所を表示する。
- 工具を取得しても工具メニューを維持。2つそろった時点を準備完了時刻として記録する。
- 機器のクリック／タップ、移動先ボタンで障害物を避けて移動し、到着後にメニューを開く。画面の矢印は短押し・長押しに対応。キー操作・モーダル・画面離脱で自動移動を停止する。
- 画面幅に合わせてマップ・ステージ一覧・操作ボタンを配置する。
- Stage1の後始末記録は、測定と回り込み確認の後で全CPがOFFになった時点だけに付ける。途中の切り分け用OFFを後始末と混同しない。

## 検証

`node --test tests/regression.cjs`

経路探索、到達不能、各設備への移動、CP後始末判定、練習の進捗登録、実力確認の判断待ち・誤判定・誤報告、および不良と回り込みを含む導通チェックの完了を検証する。

ブラウザーでは初回ガイド、工具の連続取得、移動、端子手動選択、判断ボタン、CP切り替えを確認。390px幅での表示も確認した。全10ステージの実プレイによる通し確認は未実施。
